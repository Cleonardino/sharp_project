# sharp_project
A ML-OPs project. SHARP (Smart Hand Automated Recognition Project) recognises fingers combinations

Lancer mlflow avec la commande
```bash
mlflow ui --backend-store-uri file:./mlruns
```

Puis exécuter le main et choisir les numéros correspondants pour soit télécharger, vérifier, préparer le dataset ou train un model

La config des différents trainings peut être modifiée dans le fichier de config training/src/train_config.py
